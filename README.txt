안심알림 웹앱 시제품 (PWA 기본 구성)

파일:
- index.html: 앱 화면 및 테스트 기능
- manifest.json: 홈 화면 설치용 메타데이터
- sw.js: 서비스 워커 및 캐시/알림 클릭 처리
- icon.svg: 앱 아이콘

중요:
- 이 시제품은 가상 테스트 알림만 제공합니다.
- 실제 전자감독 대상자 위치정보를 수집/추적/표시하지 않습니다.
- 서비스 워커와 PWA 기능은 file:// 로컬 파일에서 동작하지 않습니다. HTTPS 웹 호스팅이 필요합니다.
- 현재는 원격 푸시 서버가 없으므로, 앱이 닫혀 있을 때 서버가 보내는 실시간 푸시 알림은 구현되어 있지 않습니다.
- iPhone/iPadOS에서 웹 푸시를 시험하려면 지원 버전의 iOS, 홈 화면에 추가한 웹앱, HTTPS, 알림 권한 등이 필요합니다.
